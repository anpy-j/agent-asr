## 不应从这些检查推导出的结论

自动测试使用模拟神经模型，不证明 small、large-v3、R2T2 的真实识别准确率，也不证明 R2T2 在该 Windows CPU 上的速度或内存符合产品要求。

后端依赖和实际音频验证的补充结果会在本文件记录。未完成的验证不会记为通过。

## Whisper small 实际模型烟雾验证

使用 [R2T2 官方公开测试音频](https://github.com/netease-youdao/Confucius4-R2T2/blob/master/resources/test.wav)，长度 6.74 秒；加载已缓存的 Systran faster-whisper-small，CPU INT8，开启字词时间戳。

首次验证成功输出中文文本与 17 个带时间戳的字词条目，模型初始化及推理约 16.83 秒。该值包含冷加载，不能用于推导一小时直播的处理时间。没有人工参考稿，因此不报告准确率。

复验仍成功输出 17 个条目，模型初始化及推理约 13.38 秒，采样到的 worker 进程树 RSS 峰值约 780 MiB。测量包含 Windows venv 实际 Python 子进程及 FFmpeg，不包含 GPU 显存，不作为独占内存或正式性能基准。

large-v3 与 R2T2 尚未完成真实权重推理验收，首版不发布它们的准确率或速度结论。
